# Exercícios de Java — Faculdade

Este repositório reúne exercícios e pequenos projetos desenvolvidos durante meus estudos de Java na faculdade. Ele registra minha evolução e apresenta, de forma organizada, os conceitos que venho praticando <!-- — não apenas como material acadêmico, mas também para estudantes, profissionais e outras pessoas interessadas em acompanhar meu aprendizado. -->

As atividades são independentes e estão organizadas por pasta. Clique nos títulos para abrir cada projeto e acessar seus arquivos-fonte.

## 📚 Atividades

### [Leitura, escrita e criação de arquivos](./Exploring_the_interface_in_NetBeans/)
Exercícios introdutórios de manipulação de arquivos de texto: criação de arquivo, gravação de conteúdo e leitura linha a linha.

Arquivos: [`main.java`](./Exploring_the_interface_in_NetBeans/main.java), [`EscrevendoArquivo.java`](./Exploring_the_interface_in_NetBeans/EscrevendoArquivo.java) e [`EscreverArquivoUsuario.java`](./Exploring_the_interface_in_NetBeans/EscreverArquivoUsuario.java).

### [Cadastro de usuários com Java Swing](./Starting_interface_in_java/)
Interface gráfica para cadastrar nome, idade e e-mail, salvar os dados em arquivo de texto e exibir os registros em uma tabela. A pasta também contém uma tela principal de demonstração.

Arquivos: [`TelaLoginUsuario.java`](./Starting_interface_in_java/TelaLoginUsuario.java) e [`TelaPrincipal.java`](./Starting_interface_in_java/TelaPrincipal.java).

### [Bloco de notas](./PROJECT_Notes/)
Aplicação desktop com opções para criar uma nota, abrir conteúdo salvo e gravar notas em arquivos de texto.

Arquivo: [`BlocoDeNotas.java`](./PROJECT_Notes/BlocoDeNotas.java).

### [Controle de veículos](./PROJECT_control_of_vehicles/)
Interface para registrar carros e motos com placa, modelo e ano, salvar os dados localmente e pesquisar registros pela placa.

Arquivo: [`ControleDeVeiculos.java`](./PROJECT_control_of_vehicles/ControleDeVeiculos.java).

### [Agenda de contatos](./PROJECT_list_of_contacts/)
Aplicação para cadastrar contatos com nome, telefone e e-mail, fazer uma validação básica do endereço de e-mail e listar os registros salvos.

Arquivo: [`AgendaDeContatos.java`](./PROJECT_list_of_contacts/AgendaDeContatos.java).

### [Boletim de alunos](./PROJECT_report_card/)
Aplicação para registrar duas notas por aluno, calcular a média, indicar a situação conforme as regras do exercício e apresentar os resultados em uma tabela.

Arquivo: [`BoletimDeAlunos.java`](./PROJECT_report_card/BoletimDeAlunos.java).

## 🧠 Conceitos praticados

- Fundamentos de Java, classes, métodos e estruturas condicionais.
- Interfaces desktop com Java Swing, incluindo campos, botões, tabelas e caixas de diálogo.
- Criação, leitura e escrita de arquivos de texto.
- Validação básica de entradas, conversão de valores e cálculo de médias.

## 🛠️ Tecnologias

- Java
- Java Swing
- Apache NetBeans

> Os projetos refletem etapas do meu aprendizado e podem evoluir conforme eu pratico novos conceitos e aprimoro as implementações.
